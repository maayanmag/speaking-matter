Reading the image

Header
Source file, mesh size, height statistics and a SHA-256 fingerprint of the data.
OFFSET
The position of the first byte in this row, written in hexadecimal.
HEX
Each height is scaled to 0–255 and written as two hexadecimal digits, 00–FF. Brighter green means greater height.
Each row
48 successive height samples. Line breaks organize the display; they are not the stone’s outline.
DECODED / SYMBOL
The same bytes mapped to visual symbols. This is a second representation, not a decrypted message.
BITS
The row’s values are combined using XOR. Eight blocks show the resulting byte in binary.
