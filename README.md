# Speaking Matter · דומם מדבר — Digital Exhibition

A digital twin of the physical exhibition *Speaking Matter*, exploring the tension between ancient geological matter (raw stones) and digital cyber-cryptography (scanning, data extraction, encryption).

> The visitor walks through four conceptual stations — **Touch · Code · Vault · Fiction** — and watches matter transform into data, and back.

## Live URL

To be deployed at: **https://maayanmag.github.io/speaking-matter/**

## Tech stack

- **Static HTML + vanilla JS + ES modules** — no build step, deploys directly to GitHub Pages
- **Lenis** — smooth scroll with momentum (lazy, respects `prefers-reduced-motion`)
- **Three.js (r170)** — inline 3D gallery for *Possible Stones* (Station 4), lazy-loaded behind IntersectionObserver
- **Web Crypto API** — AES-GCM-256 demo for *Stone Vault* (Station 3, planned)
- **Tiny custom i18n** — `[data-i18n]` attribute hydrator, full HE/EN switch with `dir="rtl"` flip and `localStorage` persistence
- **Google Fonts** — Inter (UI), JetBrains Mono (code/hex), Heebo + Frank Ruhl Libre (Hebrew)

## Bilingual approach

The site is fully bilingual in English and Hebrew with a working header toggle.

- Locale strings live in `content/i18n.{en,he}.json` (matching key shape, generated by `tools/build_i18n.py`).
- Any DOM element with `data-i18n="path.to.key"` is hydrated on locale change. Use `data-i18n-html="true"` for trusted HTML body content.
- On toggle, `<html dir>` and `<html lang>` flip between `ltr/rtl` and `en/he`. Hebrew uses Heebo for chrome and Frank Ruhl Libre for prose.
- Choice persists in `localStorage` and is honoured on next visit.
- First visit defaults: `?lang=he` URL param → `navigator.language` → English fallback.

To regenerate the JSONs after editing source text:

```bash
cd portal
python3 tools/build_i18n.py
```

Sources: `texts/english_translations/*.md` (canonical EN copy) and `texts/*.docx` (canonical HE copy).

## Local development

No build step — open `index.html` in a browser, or for proper module loading and `fetch` of JSON:

```bash
cd portal
python3 -m http.server 8000
# → open http://localhost:8000
```

## Source assets (not deployed)

The portal lives inside the broader `speaking_matter/` source folder which contains:

- `final_installation_pics_and_vids/` — original installation photos/videos
- `milestone_*/` — fabrication, scanning, encryption, generative work
- `texts/` — the Hebrew source `.docx` files

Only the `portal/` subfolder is pushed to the public `speaking-matter` repo.
